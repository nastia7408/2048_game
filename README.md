# 2048 Game

A modern, fully functional web implementation of the classic puzzle game **2048**, built with clean JavaScript modular architecture and interactive UI controls.

## Live Preview

🔗 [View Live Demo](https://nastia7408.github.io/2048_game/)

## Technologies Used

- **JavaScript (ES6+)**: Core game logic encapsulated in a dedicated `Game` class module.
- **HTML5 & CSS3**: Responsive grid layout and dynamic cell styling.
- **Vite & Webpack / Node.js**: Modern build tools and local development server.

## Key Features

- **Robust Game Logic:** Implements all core mechanics, including sliding tiles in four directions, automatic merging of equal values, and score tracking based on merged tiles.
- **State Management:** Handles game status (`win`, `game over`, `ongoing`), move validation, and random tile generation (2 or 4 with standard probabilities).
- **Interactive Controls:** Keyboard arrow keys support alongside intuitive UI buttons (`Start`/`Restart`).
- **Dynamic Styling:** Automatic updates of cell appearance based on their numeric values.
